## Selected projects

### CICT-PPMP — AI-assisted procurement planning

A web-based procurement and budget tracking system that includes an AI-assisted budget reallocation workflow, spreadsheet ingestion, audit history, role-based access, and data export. The project uses React, TypeScript, Python, Django, and Supabase.

[View the repository](https://github.com/Jerson-Valdez/CICT-PPMP) · [Open the live app](https://cict-ppmp.vercel.app/)

### Labable — Laundry management platform

A web and mobile platform for laundry shops, with customer service tracking and an administration dashboard for orders and operations. Built with React and Firebase.

[View the repository](https://github.com/caetachi/labable) · [Open the live app](https://labable.web.app/)

### Mommy's Variety Store — Inventory and POS system

A Java desktop application for inventory and store operations, using SQL Server for its primary database.

[View the repository](https://github.com/Jerson-Valdez/BSIT2FG2_PROJECT_IM-OOP-EDP-ADB-IDA)
